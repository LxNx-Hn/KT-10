# 이동편의시설 경로 탐색

ODsay 대중교통 경로와 경로 주변의 이동편의시설을 카카오맵에서 함께 확인하는 프로토타입입니다. 출발지와 목적지를 바꿔가며 시설을 포함한 경로의 점수화 기준과 AI 모델 입력 구조를 검토하는 용도로 사용합니다.

## 주요 기능

- 카카오 장소 검색을 이용한 출발지·목적지 선택 및 좌표 변환
- ODsay 대중교통 추천 경로 조회
- 부산버스정보시스템과 연동한 승차 정류장별 실시간 버스 도착정보 및 저상버스 여부 표시
- 버스, 지하철, 버스+지하철 경로 분류
- 승하차 지점, 환승 지점, 경유 정류장과 구간별 시간·거리 표시
- 대중교통 경로선과 도보 구간 표시
- 경로별 상세 안내 펼치기
- 시설 유형별 지도 마커 표시 및 필터링

현재 포함된 시설 데이터는 다음과 같습니다.

- 무더위쉼터
- 한파쉼터
- 스마트 버스쉘터
- 전동휠체어 급속충전기
- AED

## API 역할

- **ODsay API**: 대중교통 추천 경로, 노선, 정류장·역, 경유지, 구간별 이동 정보와 경로 형상 조회
- **카카오맵 JavaScript API**: 지도 화면 표시, 장소 검색, 검색 결과의 위도·경도 변환
- **부산버스정보시스템 API**: ODsay의 부산 정류소·노선 식별자를 이용한 실시간 버스 도착정보 조회

경로 정보는 ODsay를 기준으로 사용하며, 카카오는 화면 표시와 장소 검색에 사용합니다.

## 폴더 구성

```text
ODsay/
├─ data/                  시설 원본·전처리 CSV
├─ public/
│  ├─ index.html          화면 구조
│  ├─ styles.css          화면 스타일
│  └─ app.js              지도, 검색, 경로 및 시설 표시
├─ .env.example           환경변수 입력 예시
├─ .gitignore             Git 제외 파일 설정
├─ README.md              실행 및 프로젝트 설명
└─ server.mjs             로컬 서버와 API 중계
```

## 실행 환경

- Node.js 20 이상 권장
- ODsay API 키
- 카카오맵 JavaScript 키
- 공공데이터포털 부산버스정보시스템 서비스 키
- 기본 실행 주소: `http://localhost:8080`

이 프로젝트는 Node.js 기본 모듈만 사용하므로 `npm install`은 필요하지 않습니다.

## API 키 준비

### 1. 환경변수 파일 생성

저장소를 내려받은 뒤 프로젝트 폴더에서 `.env.example`을 `.env`로 복사합니다.

PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS 또는 Linux:

```bash
cp .env.example .env
```

생성한 `.env`에 실제 키를 입력합니다.

```env
ODSAY_API_KEY=실제_ODsay_API_키
KAKAO_JAVASCRIPT_KEY=실제_카카오_JavaScript_키
BUSAN_BUS_API_KEY=공공데이터포털_부산버스_서비스키
PORT=8080
```

`KAKAO_JAVASCRIPT_KEY`에는 REST API 키가 아니라 **JavaScript 키**를 입력해야 합니다.

`BUSAN_BUS_API_KEY`에는 공공데이터포털에서 발급받은 부산버스정보시스템 서비스 키를 입력합니다. 서버가 `URLSearchParams`로 요청을 구성하므로 포털에 Encoding/Decoding 키가 함께 표시되면 Decoding 키 사용을 권장합니다.

### 2. 카카오 허용 도메인 확인

현재 프로토타입은 카카오 애플리케이션에 다음 주소가 등록된 상태를 기준으로 합니다.

```text
http://localhost:8080
```

같은 카카오 JavaScript 키를 공유하고 모든 팀원이 정확히 `http://localhost:8080`으로 접속한다면 컴퓨터마다 도메인을 따로 등록할 필요가 없습니다. 다음과 같이 접속 주소가 달라지면 해당 주소를 카카오 애플리케이션의 허용 도메인에 추가해야 합니다.

- `http://127.0.0.1:8080`
- `http://localhost:3000`
- 내부 네트워크 IP 주소
- GitHub Pages 또는 별도 배포 서버 주소
- HTTPS로 변경한 주소

## 실행 방법

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
node --env-file=.env server.mjs
```

서버가 실행되면 브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:8080
```

종료할 때는 서버를 실행한 터미널에서 `Ctrl+C`를 누릅니다.

## 사용 방법

1. 출발지를 검색하고 검색 결과에서 장소를 선택합니다.
2. 목적지를 검색하고 검색 결과에서 장소를 선택합니다.
3. 표시할 시설 유형을 체크박스로 선택합니다.
4. `선택한 장소로 경로 검색`을 누릅니다.
5. 전체·버스·지하철·버스+지하철 탭에서 경로를 비교합니다.
6. 경로 카드를 선택해 상세 승하차·환승·도보 정보를 확인합니다.
7. 버스 구간에서 첫 번째·두 번째 차량의 실시간 도착시간, 남은 정류장 수와 저상버스 여부를 확인합니다.
8. 필요하면 `새로고침`을 눌러 최신 도착정보를 다시 조회합니다.
9. 지도 마커를 눌러 시설명, 주소, 좌표와 원본 행 추적 정보를 확인합니다.

실시간 버스 도착정보는 부산버스정보시스템의 조회 시점 데이터를 사용하며 정류장별로 30초간 캐시합니다. 실시간 API가 실패하더라도 ODsay 경로와 지도는 계속 사용할 수 있습니다.

## 데이터 추적 정보

쉼터와 시설 마커에는 가능한 경우 다음 값이 표시됩니다.

- `data_index`: 헤더를 제외한 데이터 순번. 첫 데이터는 1
- `csv_row_number`: 헤더를 포함한 실제 CSV 행 번호. 첫 데이터는 2
- `source_id`: 원본 데이터의 고유번호
- `source_key`: 고유번호가 없는 데이터에 사용하는 식별용 조합값

AED는 동일한 위도·경도를 가진 행을 하나의 지도 마커로 묶고, 해당 위치의 AED 개수를 함께 표시합니다. 좌표가 없는 행은 지도 표시 대상에서 제외합니다.

## API 키 보안

- 실제 `.env` 파일은 GitHub에 커밋하지 않습니다.
- `.gitignore`에 `.env`가 등록되어 있습니다.
- `.env.example`에는 실제 키를 입력하지 않습니다.
- 공용 키를 사용하는 경우 팀 내부의 안전한 전달 수단으로 별도 공유합니다.
- 모든 팀원의 API 호출량은 공유한 키의 호출 한도에 합산됩니다.
- 실수로 키를 Git에 커밋했다면 파일만 삭제하지 말고 해당 키를 즉시 재발급해야 합니다.

카카오 JavaScript 키는 브라우저에서 사용되지만, 무단 사용 방지를 위해 허용 도메인을 필요한 주소로만 제한합니다. ODsay API 키는 `server.mjs`가 서버 측에서 읽으며 브라우저 코드에 직접 작성하지 않습니다.

## 참고 사항

- 이 프로젝트는 경로 점수화와 AI 모델 설계를 위한 1차 프로토타입입니다.
- 시설 마커가 경로 주변에 보인다는 사실만으로 최종 점수가 결정되지는 않습니다.
- 경로선, 정류장·역, 도보 구간과 시설 사이의 거리 기준은 실제 매칭 결과를 검토한 뒤 별도로 결정해야 합니다.
- API 응답과 추천 경로는 호출 시점 및 API 제공사의 정책에 따라 달라질 수 있습니다.
