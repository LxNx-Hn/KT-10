# 교통약자 및 이동취약자 맞춤형 경로 추천 PWA

> 서비스명: **미정**  
> 플랫폼: **PWA 웹앱**  
> 지도 API: **Kakao Map API 기준 개발**  
> 발표 범위: **특정 구 한정 데모**  
> 핵심 방향: **차량 내비 제외, 보행·대중교통·교통약자 접근성 중심**

---

## 1. 프로젝트 개요

본 프로젝트는 자동차 내비게이션 기능을 제외하고, 보행자와 대중교통 이용자의 실제 이동 가능성을 판단하는 **접근성 기반 경로 추천 PWA 웹앱**을 개발하는 것을 목표로 한다.

기존 지도 서비스는 빠른 길, 짧은 길, 대중교통 최적 경로를 중심으로 안내하지만, 실제 이동 과정에서 발생하는 계단, 긴 환승, 엘리베이터 부재, 저상버스 여부, 보행 부담, 날씨 위험, 온열질환 위험 등은 충분히 반영하지 못하는 경우가 많다.

본 서비스는 Kakao Map API로 기본 지도와 경로 후보를 제공받고, 자체 점수화 로직을 통해 사용자 특성에 맞는 경로를 재평가한다. 발표 단계에서는 특정 구를 한정하여 실제 데이터와 검증 가능한 대표 경로를 중심으로 구현한다.

- 특정 구 한정 데모
- 경로별 점수 검증
- 저상버스 도착 조회
- 저상버스 우선 경로 추천
- 고령자·아동·장애인·일반 사용자 프로필
- 날씨 기반 점수 반영
- 날씨 및 위험 안내
- 음성명령 기반 경로 검색·조건 변경
- 음성안내 기반 경로 설명
- 큰 UI, 버튼식 조작, 접근성 중심 화면

### 2.2 제외 기능

- 자동차 내비게이션
- 운전자용 실시간 도로 교통 최적화
- 주차 추천 및 결제

- 렌터카
- 차량 중심 모빌리티 기능

## 3. 사용자 프로필

시각약자는 별도 프로필로 분리하지 않는다. 대신 전체 서비스에서 음성명령과 음성안내를 제공하여 화면 조작이 어려운 상황에서도 핵심 기능을 사용할 수 있도록 한다.

| 프로필 | 설명 | 주요 반영 기준 |
|---|---|---|
| 일반 | 특별한 이동 제약이 없는 사용자 | 빠른 길, 보행 부담, 날씨 위험 균형 |
| 고령자 | 장시간 보행, 계단, 혼잡에 취약한 사용자 | 승강기 우선, 짧은 도보, 적은 환승, 큰 UI |
| 아동 | 보호자 동반 또는 어린이 이동을 고려한 사용자 | 안전한 횡단, 사고위험 회피, 날씨 안내, 큰 UI |
| 장애인 | 휠체어, 보행 보조, 이동 제약이 있는 사용자 | 계단 회피, 승강기 우선, 저상버스 우선, 접근성 정보 우선 |

## 4. 경로 추천 방식

### 4.1 기본 구조

```text
Kakao Map API 경로 후보 생성
        ↓
경로 후보별 접근성·대중교통·날씨 데이터 매칭
        ↓
자체 점수화
        ↓
사용자 프로필별 가중치 적용
        ↓
추천 경로 3개 제공
        ↓
점수 검증 및 설명 제공
```

### 4.2 자체 점수화 항목

- 접근성 점수
- 보행 부담 점수
- 승강기 이용 가능성 점수
- 저상버스 이용 가능성 점수
- 날씨 위험 점수
- 안전성 점수
- 데이터 신뢰도 점수

### 4.3 점수 검증 원칙

경로 점수는 반드시 검증한다. 단순 임의 점수로 처리하지 않는다.

검증 방식:

- 대표 경로 수동 검증
- 프로필별 시나리오 검증
- 계단·승강기·저상버스 반영 여부 검증
- 날씨 조건 변경 전후 경로 점수 비교
- 특정 구 내 현장 확인 또는 수동 체크포인트 확인
- 추천 결과와 실제 이동 가능성 비교

## 5. 저상버스 기능

저상버스 기능은 핵심 기능으로 포함한다.

필수 기능:

- 정류장별 버스 도착 조회
- 도착 차량의 저상버스 여부 표시
- 저상버스 우선 경로 추천
- 장애인·고령자 프로필에서 저상버스 가중치 반영
- 저상버스 정보 없음 또는 일반버스 도착 시 주의 안내
- 음성으로 저상버스 도착 여부 안내

예시 안내:

```text
5분 뒤 도착하는 81번 버스는 저상버스입니다.
```

```text
현재 추천 경로의 버스는 저상버스 여부가 확인되지 않았습니다.
```

## 6. 날씨 반영

날씨는 단순 표시가 아니라 경로 점수와 안내에 반영한다.

반영 요소:

- 기온
- 체감온도
- 강수
- 폭염
- 한파
- 풍속
- 미세먼지

예시 반영:

| 조건 | 처리 |
|---|---|
| 폭염 + 긴 실외 보행 | 감점 및 온열질환 주의 안내 |
| 한파 + 긴 대기시간 | 감점 및 대체 경로 추천 |
| 비 + 계단/경사 구간 | 감점 및 미끄럼 주의 안내 |
| 미세먼지 나쁨 + 긴 실외 이동 | 감점 및 실외 이동 주의 안내 |

## 7. 음성 기반 사용

본 서비스는 음성만으로도 핵심 이동 기능을 사용할 수 있는 구조를 지향한다.

음성으로 가능한 기능:

- 목적지 검색
- 경로 탐색
- 프로필 변경
- 조건 변경
- 저상버스 우선 경로 요청
- 날씨 회피 경로 요청
- 경로 요약 듣기
- 추천 경로 선택
- 안내 반복

예시 명령:

```text
서면역까지 가는 길 찾아줘
```

```text
고령자 기준으로 다시 찾아줘
```

```text
저상버스 우선으로 알려줘
```

```text
더위 피하는 길로 안내해줘
```

```text
첫 번째 경로 다시 설명해줘
```

단, 로그인, 리뷰 작성, 관리자 기능은 화면 조작을 병행할 수 있다.

## 10. 최종 기획 문장

본 프로젝트는 PWA 웹앱 기반의 접근성 중심 경로 추천 서비스이다. Kakao Map API를 활용해 기본 지도와 경로 후보를 제공받고, 자체 점수화 로직을 통해 고령자, 아동, 장애인, 일반 사용자의 이동 특성에 맞는 경로를 추천한다. 차량 내비 기능은 제외하며, 특정 구를 대상으로 저상버스 도착 조회, 저상버스 우선 경로 추천, 승강기 중심 경로, 날씨 기반 점수 반영, 음성명령 및 음성안내 기능을 구현한다. 경로 점수는 대표 경로와 시나리오 기반으로 반드시 검증한다.
