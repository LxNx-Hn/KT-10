# 교통약자 및 이동취약자 맞춤형 경로 추천 서비스

> 서비스명: **미정**  
> 대상 지역: **부산·울산·대구 우선, 경남·경북 확장**  
> 개발 기간: **2개월**  
> 팀 구성: **데이터 5명 / 백엔드 5명 / 프론트엔드 5명 / 추천·분석 5명**

---

## 1. 프로젝트 개요

본 프로젝트는 부산·울산·대구를 우선 대상으로 하며, 향후 경상남도·경상북도 전역으로 확장 가능한 **교통약자 및 이동취약자 맞춤형 경로 추천 서비스**를 개발하는 것을 목표로 한다.

기존 지도 서비스는 빠른 길, 짧은 길, 대중교통 최적 경로를 중심으로 안내하지만, 실제 이동 과정에서 발생하는 계단, 긴 환승, 엘리베이터 부재, 보도 접근성, 날씨 위험, 온열질환 위험, 혼잡도, 사고 위험 등은 충분히 반영하지 못하는 경우가 많다.

본 서비스는 사용자의 이동 상태와 주변 환경 데이터를 함께 분석하여, 단순히 빠른 경로가 아니라 **이동 가능하고, 안전하며, 현재 상황에 적합한 경로**를 제공하는 것을 목표로 한다.

---

## 2. 핵심 컨셉

본 서비스는 교통약자만을 대상으로 하는 제한적 서비스가 아니라, 일반 사용자도 몸이 불편하거나 피곤한 날, 짐이 많은 날, 폭염·한파·비 오는 날 등 이동 부담이 커지는 상황에서 사용할 수 있는 범용 이동지원 서비스이다.

단, 휠체어 이용자, 유모차 이용자, 고령자, 임산부, 시각약자 등 교통약자 프로필을 선택한 경우에는 계단 회피, 엘리베이터 이용 가능 여부, 정류장·역 편의시설, 음성안내, 보행 부담 등을 더 강하게 반영한다.

### 한 줄 설명

> 사용자의 이동 상태, 날씨, 교통시설, 보행환경 데이터를 종합 분석하여 현재 가장 적합한 경로를 추천하는 맞춤형 이동지원 지도 서비스.

---

## 3. 문제 정의

기존 지도 및 길찾기 서비스는 다음과 같은 한계를 가진다.

- 최단 시간·최단 거리 중심의 경로 추천
- 사용자 신체 상태나 이동 제약 반영 부족
- 계단, 엘리베이터, 에스컬레이터 등 편의시설 정보 반영 한계
- 폭염, 한파, 강수, 미세먼지 등 날씨 위험 반영 부족
- 고령자, 임산부, 휠체어 이용자, 시각약자 등 사용자 유형별 추천 차별화 부족
- 경로 추천 이유와 위험 요소 설명 부족
- 데이터 부족 지역에 대한 명확한 안내 부족

본 프로젝트는 기존 길찾기 서비스가 충분히 고려하지 못했던 **이동 가능성, 접근성, 안전성, 날씨 위험, 편의시설 접근성**을 경로 추천 기준에 포함한다.

## 5. 서비스 범위

### 5.1 우선 지원 지역

1차 지원 지역:

- 부산광역시
- 울산광역시
- 대구광역시

2차 확장 지역:

- 경상남도 주요 도시
- 경상북도 주요 도시

3차 확장 지역:

- 경상남도 전체
- 경상북도 전체

### 5.2 지역 확장 원칙

본 서비스는 특정 지역의 데이터가 모두 확보되어 있다고 가정하지 않는다. 지역별 데이터 확보 수준에 따라 제공 기능을 차등 적용한다.

| 데이터 확보 수준 | 제공 기능 |
|---|---|
| 높음 | 경로 추천, 편의시설 반영, 날씨 반영, 위험도 분석 |
| 보통 | 기본 경로 추천, 날씨 반영, 일부 편의시설 표시 |
| 낮음 | 기본 경로 및 데이터 부족 안내 |
| 없음 | 해당 지역 서비스 제한 안내 |

## 6. 핵심 기능

### 6.1 사용자 프로필 설정

필수 프로필:

- 일반
- 휠체어
- 유모차
- 고령자
- 임산부
- 시각약자
- 일시적 부상
- 피곤함
- 짐 많음
- 더위 취약
- 추위 취약

프로필별로 경로 추천 기준이 자동 적용된다.

| 프로필 | 자동 적용 기준 |
|---|---|
| 휠체어 | 계단 제외, 엘리베이터 우선, 저상버스 우선 |
| 고령자 | 도보거리 감소, 적은 환승, 낮은 경사 |
| 임산부 | 혼잡 회피, 긴 도보 회피, 실내 이동 우선 |
| 더위 취약 | 폭염 시 실외 보행거리 감점 |
| 짐 많음 | 계단 회피, 엘리베이터 우선 |

### 6.2 출발지·도착지 검색

- 현재 위치 기반 출발지 설정
- 장소명 검색
- 주소 검색
- 지도에서 직접 선택
- 최근 검색지
- 즐겨찾기

### 6.3 경로 추천

서비스는 단일 경로가 아니라, 성격이 다른 추천 경로 3개를 제공한다.

기본 추천 유형:

1. 가장 접근성 좋은 길
2. 가장 빠른 길
3. 날씨·안전 고려 길

프로필별 예시:

- 휠체어: 계단 없는 길 / 엘리베이터 우선 길 / 위험 적은 길
- 고령자: 덜 걷는 길 / 환승 적은 길 / 쉼터 가까운 길
- 더위 취약: 실외 이동 적은 길 / 쉼터 경유 길 / 빠른 길

### 6.4 경로 점수 표시

각 경로에는 다음 점수를 표시한다.

- 접근성 점수
- 안전성 점수
- 날씨위험 점수
- 보행부담 점수
- 환승편의 점수
- 편의시설 점수
- 데이터 신뢰도

### 6.5 추천 이유 제공

각 경로는 추천 이유와 주의 문구를 함께 제공한다.

예시:

> 이 경로는 계단이 없고 엘리베이터를 2회 이용할 수 있어 휠체어 이용자에게 적합합니다. 실외 보행거리가 짧아 폭염 상황에서도 비교적 부담이 낮습니다.

### 6.6 버튼식 조건 변경

필수 버튼:

- 빠른 길
- 계단 없는 길
- 덜 걷는 길
- 환승 적은 길
- 엘리베이터 우선
- 저상버스 우선
- 실내 이동 우선
- 폭염 피하기
- 비 피하기
- 안전한 길

버튼 선택 시 경로 추천 기준이 즉시 변경되고, 경로 3개가 다시 계산된다.

### 6.7 음성명령

필수 음성명령 예시:

- 계단 없는 길로 바꿔줘
- 덜 걷는 길로 알려줘
- 엘리베이터 있는 경로만 보여줘
- 더위 피하는 길로 바꿔줘
- 비 안 맞는 길로 가고 싶어
- 환승 적은 길로 바꿔줘
- 저상버스 우선으로 찾아줘
- 현재 경로 다시 설명해줘
- 다음 안내 다시 말해줘
- 가장 안전한 길로 바꿔줘

### 6.8 음성안내

음성안내 내용:

- 출발 안내
- 다음 이동 방향
- 환승 안내
- 엘리베이터 위치 안내
- 계단·급경사·위험구간 경고
- 날씨 위험 안내
- 도착 안내
- 경로 재탐색 안내

### 6.9 버튼식 챗봇

챗봇 주요 기능:

- 경로 조건 선택
- 사용자 상태 변경
- 경로 설명 요청
- 편의시설 찾기
- 위험요소 확인
- 음성안내 다시 듣기

## 7. 데이터 요구사항

### 7.1 데이터 수집 원칙

- 데이터 확보 여부를 먼저 확인한다.
- API 키 또는 데이터 신청이 필요한 경우 별도로 관리한다.
- 수집된 데이터는 지역, 좌표, 시설 유형, 갱신일 기준으로 표준화한다.
- 개인 식별 가능성이 있는 데이터는 사용하지 않는다.
- 교통카드 데이터, 유동인구 데이터 등은 집계형·비식별 데이터만 사용한다.
- 데이터 신뢰도가 낮은 경우 경로 안내에 주의 문구를 표시한다.

### 7.2 필수 데이터

| 구분 | 필요 데이터 | 활용 목적 |
|---|---|---|
| 지도 데이터 | 지도 API, 장소 검색, 좌표 변환 | 지도 표시, 출발지·도착지 검색 |
| 대중교통 데이터 | 버스 정류장, 노선, 도착, 위치 | 대중교통 경로 추천 |
| 도시철도 데이터 | 역 위치, 노선, 환승역 | 지하철 경로 추천 |
| 편의시설 데이터 | 엘리베이터, 에스컬레이터, 휠체어 리프트 | 접근성 판단 |
| 저상버스 데이터 | 저상버스 운행 여부 | 교통약자 경로 추천 |
| 날씨 데이터 | 기온, 강수, 폭염, 한파, 풍속 | 날씨 위험 반영 |
| 사고위험 데이터 | 사고다발지역, 보행자 사고 | 안전성 점수 계산 |

- 노선별 이용량

- 지역별 이동 OD 데이터

활용 목적:

주의사항:

## 9. 경로 분석 및 추천 로직

### 9.1 경로 후보 생성

지도 API 또는 경로탐색 API를 통해 기본 경로 후보를 생성한다. 경로 후보는 최소 3개 이상 확보하는 것을 목표로 한다.

후보 유형:

- 최단 시간 경로
- 최소 환승 경로
- 최소 도보 경로
- 접근성 우선 경로
- 날씨 회피 경로

### 9.2 경로별 분석 항목

| 항목 | 설명 |
|---|---|
| 총 소요시간 | 전체 이동 시간 |
| 총 이동거리 | 전체 거리 |
| 도보거리 | 실제 걷는 거리 |
| 실외 보행거리 | 날씨 영향을 받는 거리 |
| 환승 횟수 | 대중교통 환승 수 |
| 계단 포함 여부 | 계단 또는 유사 장애요소 |
| 엘리베이터 이용 가능 여부 | 경로상 엘리베이터 존재 여부 |
| 에스컬레이터 이용 가능 여부 | 보행 부담 감소 요소 |
| 저상버스 가능 여부 | 버스 이용 접근성 |
| 사고위험 | 사고다발지역 통과 여부 |
| 혼잡도 | 승하차·유동인구 기반 혼잡 추정 |
| 날씨위험 | 폭염, 한파, 비, 눈, 강풍 |
| 편의시설 | 화장실, 쉼터, 충전소 등 |
| 데이터 신뢰도 | 데이터 확보 수준과 갱신성 |

### 9.3 경로 점수

경로는 다음 점수로 평가한다.

- 접근성 점수
- 안전성 점수
- 날씨 대응 점수
- 보행 부담 점수
- 환승 편의 점수
- 편의시설 점수
- 시간 효율 점수
- 데이터 신뢰도 점수

최종 점수는 사용자 프로필에 따라 가중치가 달라진다.

### 9.4 경로 분류

| 등급 | 의미 |
|---|---|
| 매우 적합 | 현재 사용자 상태에 가장 적합 |
| 적합 | 이용 가능하며 큰 위험요소 없음 |
| 보통 | 일반적인 경로 |
| 주의 필요 | 특정 위험요소 존재 |
| 위험 | 이동 부담 또는 위험요소 큼 |
| 이용 어려움 | 사용자 조건상 이용 부적합 |

## 18. 최종 기획 문장

본 프로젝트는 부산·울산·대구를 중심으로 경상권 전역까지 확장 가능한 교통약자 및 이동취약자 맞춤형 경로 추천 서비스이다. 사용자의 이동 상태와 계단 이용 가능 여부, 엘리베이터·저상버스·정류장 편의시설, 날씨·온도·강수·사고위험 데이터를 종합 분석하여 최적 경로 3개를 제공한다. 또한 프로필 기반 자동 추천과 버튼식 조건 변경, 음성명령, 음성안내를 함께 제공하여 교통약자뿐 아니라 일반 사용자도 상황에 따라 안전하고 편리한 경로를 선택할 수 있도록 지원한다.
