# 경사·그늘 규칙 데모

## 완료 기준

현재 데모는 부산진구청→서면역 고정 후보에 대해 다음을 재현 가능하게 검증합니다.

- Copernicus DEM GLO-90 기반 경사 요약
- 요청 시각의 태양 방위각·고도각 계산
- 합성 건물 footprint·높이를 이용한 그림자 폴리곤
- 건물 footprint를 태양 반대 방향으로 스윕한 그림자와 도보 선의 정확한
  교차 길이를 이용한 그늘 비율·그늘 보행거리
- 10m 간격 시각화 구간을 이용한 지도 위 그늘·햇빛 노출 색상
- `제일 빠른 길`, `경사도 적은 길`, `그늘 많은 길` 대표 경로
- 폭염 점수에서 그늘 구간을 제외한 햇빛 노출 보행시간 반영
- Kakao 지도 또는 폴백 약도의 그늘·햇빛 노출 구간 오버레이

## 사실성 경계

`data/ai/buildings.demo.json`은 기능 검증용 합성 건물입니다. 따라서 API는 `dataQuality=demo`, `status=estimated_demo`를 반환하고 UI는 `데모 건물 높이`를 함께 표시합니다. 야간은 그늘 0%로 바꾸지 않고 `not_daylight`, 경로 geometry가 없으면 `unavailable`로 반환합니다.

합성 건물은 `ROUTE_MODE=demo`의 고정 OD에서만 사용합니다. `live` 경로는
`BUILDING_SOURCE=vworld`와 유효 키가 있을 때만 건물 그늘을 계산하며,
그 외에는 합성 건물로 바꾸거나 그늘을 0%로 대입하지 않습니다.

GLO-90은 약 90m 격자의 지형 경사이며 보도 자체의 정밀 구배가 아닙니다. 현재 값은 실제 DEM 조회 결과이지만 서비스 설명에서는 계속 `90m 지형 추정`으로 표시합니다.

그늘 범위는 건물만 포함합니다. 나무 그늘과 지형 그림자는 입력 데이터와
현장 검증이 없어 계산하지 않습니다. 실데이터에서는 버스·지하철 경로 전체를
도보로 간주하지 않고, 거리와 geometry가 모두 확인된 실외 도보 구간만
계산합니다. 대중교통 경로에서 그 정보가 없으면 비율을 만들지 않고
`unavailable`로 반환합니다.

## 공공 건물 데이터 교체 계약

실데이터 입력에는 최소한 다음 필드가 필요합니다.

- 건물 고유 ID
- 좌표계가 명시된 폐합 footprint
- 높이(m) 또는 층수와 검증된 층고 변환 규칙
- 기준일, 제공기관, 라이선스
- 높이 결측 여부와 품질 상태

결측 높이는 0m로 대체하지 않습니다. 높이가 일부만 확인된 경우 결과를
`lower_bound`로 표시하고 UI에는 `확인된 건물 그늘 최소`와
`높이 확인 건물 수/전체 건물 수`를 함께 보여 줍니다. 높이가 확인된 건물이
하나도 없으면 `unavailable`입니다. 실제 데이터 전환 시에는
이용조건·갱신주기·좌표계와 높이 단위를 표본 검증해야 합니다.

공식 데이터 두 가지를 실파일·스키마 기준으로 검사했습니다.

- [부산광역시 도시공간정보시스템 도로(건축물) 정보](https://www.data.go.kr/data/15084593/fileData.do): 실파일은 292,069행이나 좌표·도형·건물 ID가 없고, 높이 0이 136,897행이며 비현실적 극단값도 확인됐습니다. 안전한 footprint 결합 근거가 없어 감사 자료로만 둡니다.
- [VWorld GIS건물통합정보 WFS](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=bldginfo): `LT_C_BLDGINFO`에서 footprint와 `height`, 안정 식별자 후보를 같은 피처로 제공합니다. `BUILDING_SOURCE=vworld` 공급자로 구현했으며 유효 API 키와 실제 부산 응답 검증이 남았습니다.

부산 CSV와 VWorld를 추정 조인하지 않습니다. VWorld 높이 결측은 0m로 대체하지 않고 제외하며, 알려진 높이의 건물 커버리지를 응답에 남깁니다.

## 개인화와 전역학습

로그인 사용자의 후기는 사용자별 온라인 상태만 즉시 갱신합니다. 2026-07-23 승인된 초기 파일럿 정책은 후기가 누적될수록 개인 예측을 혼합하되 최대 35%를 넘지 않고, 첫 5건 동안 전역·규칙 점수를 우선합니다.

전역 후보 모델은 자동 갱신하지 않습니다. 관리자가 동의된 후기만 익명화하고 데이터 품질을 확인한 뒤 `backend/ml/export_consented_reviews.py`와 `backend/ml/train_global_candidate.py`를 수동 실행합니다. 생성물은 후보 모델이며 운영 모델을 자동 덮어쓰지 않습니다.

## 실서비스 전 남은 검증

1. 유효 VWorld 키로 부산 실제 응답·이용조건·높이 단위 검증
2. 보행로 정밀 geometry와 건물 footprint 좌표 정합 검증
3. 현장 표본으로 시간대별 그늘 비율 오차 측정
4. ODsay 키 재발급 또는 인증 설정 수정
5. Kakao REST/OAuth 키, PostgreSQL, 세션 비밀키 설정
6. 실제 사용자 후기 파일럿으로 승인된 개인화 최대 영향 35% 재검토
7. 관리자 후보 학습 결과의 오프라인 비교 보고서와 운영 승인을 위한 절차
