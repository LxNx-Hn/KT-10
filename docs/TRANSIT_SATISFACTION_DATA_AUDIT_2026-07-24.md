# 2023~2025 대중교통 만족도 데이터 감사

기준일: 2026-07-24 (Asia/Seoul)

## 결론

제공받은 압축파일은 161개 시군의 지역·집단별 대중교통 만족도 평균입니다.
경로 대안, OD, 경사, 그늘, 경로 피처, 선택 순위가 없으므로 현재
XGBRanker의 경로 추천 라벨로 사용할 수 없습니다.

즉시 반영한 것은 다음입니다.

- 원본 ZIP과 연도별 XLSX의 SHA-256 고정
- ZIP/XLSX 경로·크기·압축률 검사
- 161개 지역과 `Index`/`Table` 순서 일치 검사
- 연도별 지표 스키마·단위 해시
- 문자 `,` 결측과 집계행 부재의 명시적 보존
- 숫자 범위, 중복 지역·집단 키, 프로필 커버리지 감사
- 경로 라벨 사용 금지와 향후 허용 범위를 기계 판독 가능한 정책으로 기록

원본과 실제 점수 관측값은 저장소에 넣지 않았습니다. 원본 안에서 출처 URL,
조사기관, 방법론, 표본 수, 가중치, 척도, 라이선스와 재배포 조건을 확인할
수 없기 때문입니다.

## 파일 계약과 재현

감사 결과의 고정 요약은
`data/audits/public_transport_satisfaction_2023_2025.audit.json`입니다.
원본을 보유한 관리자는 다음처럼 전체 검사를 재현할 수 있습니다.

```powershell
$env:PYTHONPATH = 'ai'
$SurveyArchive = '승인된_조사_압축파일.zip'
.\.venv\Scripts\python.exe -m data_tools.transit_satisfaction `
  --archive $SurveyArchive `
  --output cache\transit-satisfaction.audit.json
```

실제 점수까지 정규화한 로컬 산출물은 이용·재배포 조건을 확인한 뒤에만
명시적으로 만들 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m data_tools.transit_satisfaction `
  --archive $SurveyArchive `
  --output cache\transit-satisfaction.normalized.json `
  --include-observations `
  --acknowledge-license-reviewed
```

`cache/`는 Git에서 제외됩니다. 원본이나 정규화 점수가 의도치 않게
커밋되지 않습니다.

## 구조와 품질

| 연도 | 지역 | 지표 | 집계행 | 숫자 | 문자 `,` 결측 | 실질 1~7 범위 밖 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 2023 | 161 | 29 | 2,452 | 70,501 | 607 | 55 |
| 2024 | 161 | 21 | 2,452 | 51,018 | 474 | 0 |
| 2025 | 161 | 23 | 2,425 | 52,098 | 3,677 | 0 |

2023 관측 범위는 약 0.955~8.133입니다. 2024·2025의
`7.000000000000001`은 `1e-9` 허용오차 안의 부동소수 표현으로 처리하되
원값은 바꾸지 않습니다. 2023의 범위 이탈값은 원 조사 산식을 확인하기
전까지 자르거나 재척도화하지 않습니다.

지하철 집계행은 매년 43개 지역에만 있습니다. `21회 이상` 집계행은
2023·2024년 156개 지역, 2025년 128개 지역에만 있습니다. 행 자체가 없는
경우도 결측이므로 새 행을 만들거나 0으로 채우지 않습니다.

연도별 지표 수가 다르고 정확히 같은 이름의 교집합도 제한적입니다.
2024의 접근·대기 문항이 2025에는 최초 탑승과 환승 문항으로 분리되는 등
의미 변화가 있으므로 단순 열 위치나 유사 문자열로 자동 결합하지 않습니다.

## 부산에서 확인되는 맥락

부산은 구·군이나 도로·노선 단위가 아니라 광역시 전체 한 블록입니다.
전체 전반 만족도는 2023년 4.9433, 2024년 4.9323, 2025년 4.9852입니다.
2025년 부산 전체에서 상대적으로 낮은 항목은 차량 혼잡도 4.1631,
운전자 안전 4.4853, 비상 대처 4.5027, 환승정보 4.5391,
교통약자 시설 4.5528입니다.

상대적으로 낮은 항목과 조사 문항 taxonomy는 비모델 후기 설계의
우선순위를 정하는 참고로만 사용했습니다. 실제 경로 후기에 혼잡, 환승
안내·정보, 교통약자 시설 이용 불편의 선택형 1~5 직접 관측 항목을
nullable로 추가했습니다. 그러나 조사 만족도가 낮다는 사실만으로
사용자가 해당 경로 특성을 더 중요하게 여긴다고 추론하거나, 이 관측
항목과 조사 평균으로 현재 개인화·규칙·전역 relevance를 자동 변경하지
않습니다.

## 프로필과 모델 적용 경계

| 앱 프로필·상황 | 조사에서 확인되는 집계 | 현재 사용 |
| --- | --- | --- |
| 일반 | 전체 | 도시 맥락만 가능 |
| 고령자 | 60대 이상 | 도시 맥락만 가능 |
| 청소년 | 10대·20대 | 직접 매핑 기준 없음 |
| 아동 | 없음 | 사용 불가 |
| 장애인 | 없음 | 사용 불가 |
| 임산부 | 없음 | 사용 불가 |
| 짐 많음 | 없음 | 사용 불가 |

`교통약자 시설`은 서비스 만족도 문항이지 장애인·임산부 응답자 라벨이
아닙니다. 이를 프로필 선호로 변환하지 않습니다.

현재 랭커는 같은 실제 OD의 복수 경로, 불변 피처 스냅샷,
`group_id`, `route_id`, `profile`, 0~4 relevance와 평가자 정보를
요구합니다. 이 조사에는 해당 계약이 전혀 없습니다. 같은 도시 평균을
모든 후보에 넣으면 순위를 구분하지 못하고, 임의로 경로 피처에 결합하면
데이터가 지지하지 않는 관계를 발명하게 됩니다.

## 다음 데이터 중심 고도화

1. 조사 제공처에서 출처 URL, 라이선스, 코드북, 표본 수와 가중치 산식을
   확보합니다.
2. 이용조건이 확인되면 조사 점수는 `survey_context` 독립 자산으로만
   배포하고, 추천 피처·라벨과 물리적으로 분리합니다.
3. 구현한 혼잡·환승 안내·교통약자 시설 직접 관측값은 현재 설명·감사
   데이터로만 저장하고, 학습 사용은 동의와 관리자 검토를 거칩니다.
4. 실제 경로 후기와 조사 집계를 동일시하지 않고, 충분한 표본이 쌓인 뒤
   도시 수준 외적 타당성 비교에 사용합니다.
5. 운영 모델은 계속 실제 경로 스냅샷과 사람 평가를 기준으로 관리자
   수동 승격만 허용합니다.
