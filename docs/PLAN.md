# 제품·검증 계획

## 확정 방향

- 서비스: 교통약자 및 이동취약자 맞춤형 보행·대중교통 경로 추천
- 범위: 부산 전역, 실제 MVP 검증은 부산역 일대 우선
- 지도: Kakao Maps 배경지도와 폴리라인 오버레이
- 후보: ODsay 대중교통 + TMAP/OSMnx 보행
- 추천: 9인 실제 라벨 기반 learning-to-rank, 숫자 점수 대신 경로 특성 표시
- 개인화: 카카오 로그인 사용자만 실제 후기 기반 온라인 모델 적용; 게스트 미적용
- 장기 학습: 명시적으로 동의한 후기만 익명화하고 작은 비중으로 후보 모델에 반영, 전문가 평가 전 운영 교체 금지
- 사고정보: 현재 서비스·모델에서 제외

## 프로필과 조건

현재 앱 프로필은 일반·고령자·아동·장애인입니다. 자문에서 제안된 청소년·임산부는 AI 학습 스키마까지 준비되어 있으나, 프론트 노출과 초기 라벨링 범위는 팀 결정 후 확정해야 합니다.

매번 달라지는 `짐 많음`, `계단 회피`는 검색 화면에 둡니다. 휠체어, 보행보조기, 시각·청각 안내 필요, 계단 회피 필수, 최대 도보거리는 로그인 프로필에 저장합니다. 날씨 회피와 환승 선호는 장기 프로필 항목에서 제외합니다.

## 모델 검증

1. 부산역 중심의 복수 OD와 이동조건 조합에서 실제 후보를 생성한다.
2. 9명이 각 후보를 0~4 relevance로 라벨링한다.
3. 동일 OD 그룹이 검증 경계를 넘나들지 않도록 그룹 단위 평가를 수행한다.
4. NDCG@3, 후보쌍 선호 정확도와 프로필별 오류 사례를 기록한다.
5. 공단 전문가 및 가능하면 실제 교통약자에게 경로·서비스 평가를 받는다.
6. 운영 후기는 개인화에는 크게, 동의 기반 전역 후보 학습에는 제한적으로 반영한다.

## 남은 외부 의존성

- ODsay/TMAP/Kakao/OpenWeather/공공데이터 키 입력 및 실응답 계약 테스트
- 9인 초기 라벨 완성 및 운영 모델 학습
- 공단 제공 예정 만족도·교통카드·DRT 데이터 수령
- 역사 시설 좌표·운영상태 수령 또는 구조도 기반 가공
- 데이터 카탈로그의 공식 URL·라이선스 확인
- 실제 사용자·전문가 부산역 권역 검증
